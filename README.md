#  Librería El Saber

**Proyecto Final - Talento Lab | Desarrollo Front-End**

Este proyecto forma parte de la pre-entrega del curso Front-End Trainee.  
Representa un sitio web de e-commerce para una librería ficticia llamada **“Librería El Saber”**, desarrollada con **HTML, CSS y buenas prácticas semánticas**.

---

## Estructura del Proyecto

El sitio está organizado con una estructura semántica clara:
- **Header:** incluye logo y título principal.
- **Nav:** lista de navegación interna (Inicio, Catálogo, Contacto).
- **Main:** contiene las secciones de productos, reseñas y formulario de contacto.
- **Footer:** información de contacto y derechos reservados.

---

## Formulario de Contacto

El formulario permite enviar consultas mediante **Formspree**, con los siguientes campos:
- Nombre (`input type="text"`)
- Correo electrónico (`input type="email"`)
- Mensaje (`textarea`)

---

## Estilos CSS

- Archivo externo: `styles.css`
- Tipografía: **Montserrat**, importada desde Google Fonts.
- Paleta de colores personalizada:
  - `#B77466`
  - `#FFE1AF`
  - `#E2B59A`
  - `#957C62`
- Uso de **Flexbox** para distribuir productos.
- Uso de **CSS Grid** para organizar reseñas.
- **Media Queries** aplicadas para diseño responsivo en dispositivos móviles.
